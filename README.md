# Elbert County Land Ownership Explorer

Single-file web app that ranks landowners in Elbert County, Colorado using the
county assessor's public GIS API. Click owners to highlight their parcels on the
map (multi-select supported); the "Who owns the county" panel breaks acreage and
value down by ownership class.

Open `index.html` (or the GitHub Pages link) and click **Load parcel data**.

Data: Elbert County public tax-parcel layer — informational/reference use only.
